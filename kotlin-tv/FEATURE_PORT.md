# Android 14 功能移植版

本文记录 0.10.0 基线；0.11.0 新增和覆盖的行为见 [FEATURE_COMPLETION.md](FEATURE_COMPLETION.md)。

主要目标设备：小米电视 S85 Mini LED / Android 14。原 Android 6 兼容要求已取消，不再把 API 23 测试作为交付门槛；既有可用的兼容实现没有为提高系统门槛而删除。

保留 `com.hongguotv.nativeapp`、原有本地签名及 `native-library-v1` 数据。安装包版本高于 0.9.3。保持单播放器、下一集有界预加载、定时停止优先、已修复的网站搜索兜底及持久随机设备身份。设置页和应用内更新继续移除。

## 功能与入口

移植和验证状态在最终交付的验证说明中逐项记录，不能把下列设计范围当作全部实机验收结果。

- 搜索：遥控器字母数字键盘、联想词、历史、跨类型搜索、连续加载与失败重试。
- 找剧和榜单：真实短剧/漫剧/AI 等服务端分类、组合筛选、多榜单、相关推荐和分季导航。
- 播放：设备解码能力探测、失败学习和降级，硬件/软件优先选择，单播放器换集；按剧片头片尾、跨季衔接和自定义遥控快捷键。
- 账户：官方 App 扫码登录、本机/账户收藏和历史分开、预约及相关作品。账号登录需用户后续在电视扫码，测试不使用真实账号凭据。
- 预览：独立入口，不抢占普通首页的续播；关闭或离开后释放播放资源。
- 评论和弹幕：只读、默认关闭，允许按观看偏好调整；本版本不发送评论、点赞或回复。
- 收藏和工具：分组、同剧新季提示、双副本备份恢复、统计、接口自检、外观选项、随机荐剧。新季提示依据确认的分季信息，首次发现显示“可看下一季”，不推断上线时间。
- 备份：私有目录双副本默认手动、每日自动备份可选；另可通过系统目录选择器授权外部目录，卸载重装后重新选择该目录恢复。手机二维码仍可导出本机片单。账号登录、设备标识和片源接口不会混入导出。
- 片源：用户自行导入的可选源，默认空；与官方本机记录隔离，不内置第三方内容站点。
- 电视桌面频道：仅在系统支持 TV Provider 时手动添加；小米桌面是否展示以真机系统为准。

## 明确边界

账户收藏分页和手机逐集逐秒双向进度并非参考项目已完整验收的能力。实际账号核对、真实电视解码/遥控手感、以及小米桌面频道展示需设备验收。服务器返回变化可影响搜索联想、推荐、评论或账户数据，不作永久可用保证。

私有 MPV 原生实现、独立桌面/手机/webOS 客户端不属于可直接移植的公开 Android 功能；本项目采用公开可审查的系统/Media3 解码选择。保留必要缓冲与错误提示，网络未准备好时不伪装为绝对无缝播放。

## 构建

使用 JDK 17、Android SDK 36、Gradle Wrapper，执行 `:core:test :app:testDebugUnitTest :app:lintDebug :app:assembleRelease`。本机签名配置不随源码归档；复现者须提供自己的签名配置。依赖与源码许可证见 NOTICE.md 和 LICENSE。

测试的 Robolectric Maven 缓存可通过 `HONGGUOTV_TEST_MAVEN_CACHE` 指定；默认放在工程 build 目录。仅在做签名升级验证时设置 `HONGGUOTV_SIGN_DEBUG=1`，让本地调试包使用 delivery 签名；常规调试构建使用标准调试签名。交付 APK 为 release 构建。
