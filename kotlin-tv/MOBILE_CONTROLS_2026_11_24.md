# 手机播放菜单修复（v0.11.16）

手机点击播放画面原来没有菜单入口；自定义文字按钮允许触摸获取焦点，第一次点击可能只获取焦点而不执行动作。播放工具行超出窄屏后也没有横向滚动入口。

本次修复在保留自定义播放控制的前提下增加画面单击显示/收起菜单、直接倍速按钮和收起按钮。两行工具均可横向滑动；普通文字按钮和选集按钮保留遥控器焦点，但不再由第一次触摸获取焦点。电视设备继续显示遥控器提示。

涉及生产文件：`MainActivity.kt`、`EpisodePanel.kt`；版本号递增为 versionCode 30。原有取流、Media3 播放、预加载、换集和结束事件、账号/观看记录存储、启动与手动更新检查实现保持不变。包名及原证书保持不变，支持覆盖更新。

## 验证

- 本地单元回归：`:app:testDebugUnitTest`。新测试派发真实 `MotionEvent`，覆盖画面单击、首次选集点击、首次点击集数和遥控器入口。单元测试不访问外网，不作为正片播放验收。
- 隔离调试包：`com.hongguotv.nativeapp.localmobile01116`，API 34 模拟器；设备测试仅在显式参数 `-e mobilePlaybackControls true` 下执行。
- `MobilePlaybackControlsIntegrationTest` 用真实 App 取流及 Media3 播放《全球死考》第七季第 1、2 集，以 `sendPointerSync` 注入触摸，核对倍速实际生效及持久化、取消选集保持播放/暂停意图、选择第 2 集后媒体 ID 与播放推进，以及窄屏工具可达性；再用真实按键验证遥控器跨行、横滚、确认与返回焦点恢复。
- 设备测试属于触摸交互与短时原生播放验证，不是本版自然播完整集的证明。v0.11.15 的完整第 1 集自然结束并自动进入第 2 集证据见 `PLAYBACK_FIX_2026_11_24.md`；本次不更改该播放状态机。
- 实体手机、小米 S85 实测由用户覆盖更新后确认；未操作实体手机、电视网络或清理用户数据。

具体测试统计与发布产物绑定见对应 GitHub Actions 构建记录及发布附件 `build-verification.json`。

## 风险与回滚

控件字体较大或极窄屏幕仍需滑动菜单。保留遥控器操作路径，并通过焦点/返回回归验证。若需回退，基于上一版源码重新生成更高 versionCode、原证书修订包覆盖安装；不要卸载应用或清除数据，以免丢失本地账号和记录。
